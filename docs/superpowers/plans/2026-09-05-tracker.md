# Tracker Enhancements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add catalog-product onboarding to the Tracker Add Stock modal, per-product + global display currency with a user-editable FX table, and four extras (converted dashboard, sale-modal currency, inline threshold/supplier edit).

**Architecture:** Backend persists `FxRate` rows and `User.displayCurrency`; all money math stays in stored currencies and the frontend converts display-only via a `convertCurrency` util. Reuses existing `syncSingle`, `addStock`, `PUT /tracker/:id` endpoints.

**Tech Stack:** NestJS 11 + Prisma 7 + PostgreSQL, Next.js 16 + React 19, axios, recharts, sonner. Backend tests: jest. Frontend has no test runner — verification is `tsc --noEmit`, eslint, and defined manual browser checks.

## Global Constraints

- Global API prefix is `api` — routes live under `/api/`.
- Global `ValidationPipe`: `whitelist: true, transform: true, forbidNonWhitelisted: true` — all new DTOs need class-validator decorators.
- Prisma v7: `prisma.config.ts` + `PrismaPg` adapter; schema changes apply via `npx prisma generate` + `db push` on startup (`PrismaService.onModuleInit`).
- JWT guard on all tracker/users routes; userId-scoped queries everywhere.
- Supported currencies, verbatim: `USD, EUR, GBP, INR, JPY, AUD, CAD`. Seed rates-to-USD (approximate, user-editable): `EUR 0.92, GBP 0.79, INR 83.2, JPY 149.5, AUD 1.52, CAD 1.36` (USD implicit 1, never stored).
- Dark theme, glassmorphism, `bg-[#0c0c0c]` modals — match existing tracker page.
- Frequent commits, one task = one commit minimum.

```ts
// backend/src/tracker/dto/fx-rates.dto.ts
import { IsString, IsNumber, IsArray, ValidateNested, IsIn, Min } from 'class-validator';
import { Type } from 'class-transformer';
import { ApiProperty } from '@nestjs/swagger';

export const SUPPORTED_CURRENCIES = ['USD', 'EUR', 'GBP', 'INR', 'JPY', 'AUD', 'CAD'] as const;

export class FxRateItemDto {
  @ApiProperty({ enum: SUPPORTED_CURRENCIES })
  @IsString()
  @IsIn([...SUPPORTED_CURRENCIES])
  currency!: string;

  @ApiProperty({ example: 83.2 })
  @IsNumber()
  @Min(0.000001)
  rateToUSD!: number;
}

export class UpdateFxRatesDto {
  @ApiProperty({ type: [FxRateItemDto] })
  @IsArray()
  @ValidateNested({ each: true })
  @Type(() => FxRateItemDto)
  rates!: FxRateItemDto[];
}
```

- [ ] **Step 4: Implement service methods** (append to `TrackerService`; add `BadRequestException` to `@nestjs/common` imports; define `FX_SEED_DEFAULTS` + `SUPPORTED_CURRENCIES: string[]` at top of the service file — keep the DTO's `as const` tuple separate to avoid a readonly-`includes(string)` type error)

```ts
const FX_SEED_DEFAULTS: Record<string, number> = {
  EUR: 0.92, GBP: 0.79, INR: 83.2, JPY: 149.5, AUD: 1.52, CAD: 1.36,
};
const SUPPORTED_CURRENCIES = ['USD', 'EUR', 'GBP', 'INR', 'JPY', 'AUD', 'CAD'];

async getFxRates(userId: string) {
  let rows = await this.prisma.fxRate.findMany({ where: { userId } });
  if (rows.length === 0) {
    await this.prisma.fxRate.createMany({
      data: Object.entries(FX_SEED_DEFAULTS).map(([currency, rateToUSD]) => ({
        userId, currency, rateToUSD,
      })),
      skipDuplicates: true,
    });
    rows = await this.prisma.fxRate.findMany({ where: { userId } });
  }
  return rows.map((r) => ({
    currency: r.currency,
    rateToUSD: Number(r.rateToUSD),
    updatedAt: r.updatedAt,
  }));
}

async updateFxRates(userId: string, rates: Array<{ currency: string; rateToUSD: number }>) {
  for (const r of rates) {
    if (!SUPPORTED_CURRENCIES.includes(r.currency) || r.currency === 'USD') {
      throw new BadRequestException(`Unsupported currency: ${r.currency}`);
    }
    if (!Number.isFinite(r.rateToUSD) || r.rateToUSD <= 0) {
      throw new BadRequestException(`Invalid rate for ${r.currency}`);
    }
  }
  for (const r of rates) {
    await this.prisma.fxRate.upsert({
      where: { userId_currency: { userId, currency: r.currency } },
      update: { rateToUSD: r.rateToUSD },
      create: { userId, currency: r.currency, rateToUSD: r.rateToUSD },
    });
  }
  return this.getFxRates(userId);
}
```

```ts
export const CURRENCY_OPTIONS = [
  { value: 'USD', label: '$ USD' },
  { value: 'EUR', label: '€ EUR' },
  { value: 'GBP', label: '£ GBP' },
  { value: 'INR', label: '₹ INR' },
  { value: 'JPY', label: '¥ JPY' },
  { value: 'AUD', label: 'A$ AUD' },
  { value: 'CAD', label: 'C$ CAD' },
];

export interface FxRate { currency: string; rateToUSD: number; updatedAt: string; }

export function convertCurrency(amount: number, from: string, to: string, rates: FxRate[]): number {
  if (!Number.isFinite(amount) || from === to) return amount;
  const fromRate = from === 'USD' ? 1 : rates.find((r) => r.currency === from)?.rateToUSD;
  const toRate = to === 'USD' ? 1 : rates.find((r) => r.currency === to)?.rateToUSD;
  if (!fromRate || !toRate) return amount;
  return (amount / fromRate) * toRate;
}
```
